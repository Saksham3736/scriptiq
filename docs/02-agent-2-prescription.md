# Agent 2 — Prescription Agent

## Overview

The Prescription Agent is the core AI component of the AI Prescription Assistant.

Its job is to read the transcript generated by the Speech Agent and convert it into a structured prescription.

This agent uses the **Gemini API** to understand the doctor's conversation and organize the information into a standardized format.

> **Important:** This agent should **not diagnose diseases or recommend medicines on its own.** It should only extract and organize the information explicitly provided by the doctor.

---

# Objective

Convert the doctor's transcript into a structured prescription that can be reviewed by the doctor before generating the final PDF.

---

---

# Responsibilities

The Prescription Agent should:

- Read the transcript.
- Identify patient details.
- Extract diagnosis.
- Extract prescribed medicines.
- Extract dosage and frequency.
- Extract medicine duration.
- Extract meal instructions (Before/After food).
- Extract investigations (if any).
- Extract general advice.
- Extract follow-up date.
- Generate a structured prescription.

---

# Input

The transcript received from Agent 1.

Example:

```
Patient Name Rahul Sharma.

Age 24.

Complaining of fever and sore throat since two days.

Diagnosis Viral Fever.
```

# Validation

Before sending the prescription to the PDF Agent, verify:

- Patient name exists (if provided).
- At least one medicine is present.
- Diagnosis field is available (if mentioned).
- JSON is valid.
- No duplicate medicines.
- Required fields are not null.

If validation fails:

Display an error and allow the doctor to edit the prescription manually.
